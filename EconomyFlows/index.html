Issuance and burn

What the protocol mints per day (block rewards) and what it destroys per day (fees and penalties). Monthly averages.
Issuance, FIL per day
Block rewards minted. Vesting also adds to circulating supply but is not issuance; see the accounting line above.
Burn, FIL per day
All burn: gas base fees, overestimation, batch fees, SP penalties. The 2020-21 peak is onboarding gas; today most burn is SP penalties.

Issuance offset

Burn divided by issuance. 1.0x means supply-neutral: the network destroys as much FIL as it mints. This is ultrasound.money's headline ratio, computed for Filecoin.
Issuance offset by month, burn as % of issuance
Computed from the two series above: monthly burn / monthly issuance.

Method

  • Backbone, rebuilt daily: everything on this page except the FIL price is read from seed.json, which a GitHub Action rebuilds every day around 07:00 UTC by running build_seed.py against the Filecoin Data Portal dataset daily_network_metrics.parquet (cumulative daily supply, issuance and burn). The browser fetches no chain data; the only live call is the CoinGecko price.
  • Burn by mechanism is the one series not from the portal: its daily metrics do not itemize burn by mechanism reliably (recent rows zero the breakdown columns while total burn continues; checked 2026-08-26), so the same daily rebuild pulls the split from the Starboard Network Health API (/v2/v2/gas/daily_network_fee_breakdown).
  • Filecoin Onchain Cloud row: FOC contract index (FilecoinPay + PDPVerifier events, FilOzone/filecoin-pay), as of 2026-08-26: 63.30 FIL burned via 49 fee-auction claims plus 1.44 FIL of PDP proof fees, plus negligible direct FIL-rail fees.
  • Definitions: circulating supply per the protocol definition. Issuance = mined block rewards. Burn = base fees + gas overestimation + batch fees + SP penalties; miner tips are excluded (paid to block producers, not burned). Deliberately out of scope: business-lens metrics such as the revenue coverage ratio (burn vs block rewards + public goods funding); those live in the FIL Flowmeter.

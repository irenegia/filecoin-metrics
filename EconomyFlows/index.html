q&a

Short answers for Ethereum-native readers landing on a Filecoin monetary dashboard.

What is Filecoin's version of "ultra sound"?

For this page it is the issuance-offset lens: protocol burn divided by block-reward issuance. Higher offset means more of the newly minted FIL is neutralized by burn.

How is FIL burned?

Filecoin burns gas base fees, gas overestimation, sector batch fees, and storage-provider penalties. Miner tips are paid to block producers, not burned.

Why is Filecoin different from Ethereum here?

Ethereum burn is mainly transaction demand after EIP-1559. Filecoin burn also reflects storage-provider operations and penalties, so this dashboard separates issuance, burn mechanisms, and supply accounting.

Method

  • Backbone, rebuilt daily: everything on this page except the FIL price is read from seed.json, which a GitHub Action rebuilds every day around 07:00 UTC by running build_seed.py against the Filecoin Data Portal dataset daily_network_metrics.parquet. The browser fetches no chain data; the only live call is the CoinGecko price.
  • Burn by mechanism comes from the Starboard Network Health API (/v2/v2/gas/daily_network_fee_breakdown) because the portal's daily metrics do not itemize burn by mechanism reliably.
  • Filecoin Onchain Cloud row: FOC contract index (FilecoinPay + PDPVerifier events, FilOzone/filecoin-pay), as of 2026-08-26: 63.30 FIL burned via 49 fee-auction claims plus 1.44 FIL of PDP proof fees.
  • Definitions: circulating supply per the protocol definition. Issuance = mined block rewards. Burn = base fees + gas overestimation + batch fees + SP penalties. UX inspiration: ultrasound.money; this page uses original Filecoin-specific copy, colors, and data.
